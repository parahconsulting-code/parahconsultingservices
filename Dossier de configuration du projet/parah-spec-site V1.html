Un cap clair pour s'orienter, un socle solide pour bâtir.

La plateforme réunit deux missions : un site vitrine qui présente les services et formations de PARAH Consulting, et une application de tests psychotechniques — RIASEC, intelligences multiples, aptitudes — qui aide chacun à trouver sa direction.

Modèle de données

Cinq fiches reliées entre elles : un utilisateur passe des tests, chaque test contient des questions, chaque question des options notées.

  • email unique
  • nom, prénom string
  • téléphone optionnel
  • password hash
→ tests[], rdvs[]
  • slug unique
  • titre, description
  • duréeMin int
→ questions[]
  • texte string
  • ordre int
← test · → options[]
  • texte string
  • valeur score
  • dimension optionnel
← question
  • scores json { dimension: score }
  • interprétation texte optionnel
  • createdAt date
← user · ← test

W

Limites du terrain

Trois postes de contrôle pour garder le chantier sous contrôle.

Toujours

  • TypeScript strict
  • Valider les entrées (Zod)
  • Responsive mobile-first
  • Accessibilité (a11y)
  • Tests sur fonctions critiques
  • Lint + typecheck avant commit

Je demande d'abord

  • Ajouter une dépendance npm
  • Modifier le schéma Prisma
  • Changer l'architecture des pages
  • Ajouter une API externe
  • Modifier la config Tailwind

Jamais

  • Commiter des secrets / clés API
  • Supprimer des tests sans approbation
  • Ignorer les erreurs TypeScript
  • Style inline sans raison
NW

Critères de succès

Ce qui doit être vrai avant de considérer le cap atteint.

  • Toutes les pages vitrine reproduisent le design des fichiers HTML existants
  • Les 7 tests d'orientation sont fonctionnels avec scoring automatique
  • L'inscription et la connexion fonctionnent
  • L'utilisateur peut voir l'historique de ses résultats
  • Le site est responsive (mobile + desktop)
  • Lighthouse performance > 80
